# Староста + автоматическое расписание БГТУ (v10)

В этой версии приложение получает расписание автоматически по одной кнопке через небольшой Node.js API.

## Что настроено

- 09.03.02 — «Системы искусственного интеллекта и обработка больших данных»
- бакалавриат
- очная форма
- Факультет информационных технологий
- О-26-ИСТ-СИИ-Б
- 2026–2027, 1 семестр
- нечётная и чётная недели хранятся отдельно
- ручной копипаст расписания больше не нужен

## Запуск

Требуется Node.js 18+.

```bash
npm test
npm start
```

После запуска открой:

`http://127.0.0.1:8787/`

Для PWA и нормальной работы с телефона нужен HTTPS на внешнем адресе. Обычно ставят Nginx/Caddy перед Node.js и проксируют `/api/` на `127.0.0.1:8787`.

## Быстрый тест HTTP без сайта БГТУ

Контейнер/машина может проверить весь путь браузер → API → разбор, не нагружая БГТУ:

```bash
MOCK_BGTU=1 npm start
```

В браузере/`curl`:

```bash
curl http://127.0.0.1:8787/api/health
curl 'http://127.0.0.1:8787/api/bgtu/schedule'
```

`MOCK_BGTU` нужен только для тестов, в обычном режиме его не устанавливать.

## Что делает сервер в боевом режиме

1. Открывает официальный раздел расписания БГТУ.
2. Берёт текущую нечётную/чётную неделю из заголовка страницы.
3. POST `namedata=group` получает список групп и находит точное имя `О-26-ИСТ-СИИ-Б`.
4. POST `namedata=schedule` получает HTML расписания выбранной группы.
5. Разбирает дни, время, предмет, тип, преподавателя и аудиторию.
6. Сохраняет на клиенте только шаблоны, созданные из БГТУ, не трогая ручные шаблоны пользователя.
7. При открытии даты приложение автоматически подставляет пары БГТУ этой даты.

## Важное про текущий механизм БГТУ

Параметр недели не передаётся отдельным POST-полем в коде страницы. Поэтому сервер сначала определяет текущую неделю по заголовку страницы, а если AJAX-ответ содержит две строки одного временного слота, они трактуются как верхняя (нечётная) и нижняя (чётная).
